# Security boundary

Use synthetic or public inputs in a local research environment. Stage immutable model snapshots and use safetensors for runtime weights. Keep private records, tokens, training outputs and database files outside version control. Restrict service listeners and review dependencies before exposing a network endpoint. No person-identifying records are required for the demonstration.

The orchestrated workflow uses locally staged models with Hugging Face offline mode. The preliminary downloads, package installation, advisory checks and optional GitHub publication require network access. Audit evidence and outstanding deployment controls are recorded in the portfolio index.
